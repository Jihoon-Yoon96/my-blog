# 왜 시작하게 됐느냐..
영업직으로 근무 중인 친한 형이 오랜만에 전화로 근황을 전하면서, 나에게 본인이 기획한 유통업에서 AI를 활용한 본인 기획안의 실현 가능성에 대해 자문을 구했다. 실제로 출시될 기획안은 아니고, 형내 회사에서 진행되는 "AI 활용안 기획 대회(?)"에 쓰일 데모가 필요하다는 것이었다. 그 형이 나와 같이 교육학과를 졸업했기에, 주변에 IT와 관련해서 자문을 구할 사람이 많지 않았을 것이다(나도 그런데 ㅠ..).

아무튼, 이런 저런 형의 기획내용을 듣다가 문득 "어? 이거 바이브코딩으로 만들어볼까?"하는 생각이 스쳤다. 형이 말해준 기획안들이 구체적으로 잡혀있는 것들이 아니라서 사실상 기획안부터 다듬어가면서 작업해야 했기에 시간이 꽤나 쓰일 것 같았지만, 반복되는 회사 업무로 지쳐있는 내게 새로운 인사이트를 제공해줄 것만 같아서 "형, 내가 이거 대강 만들어 볼게" 라고 질러버렸다..!

# 서비스 기획

형이 생각한 큰 틀은 다음과 같다.
유통업체나 마트에 사내 제품들을 팔아야하는데, 비슷한 제품군들의 정보를 알아내기 위해선 "신고번호"를 입력해서 하나하나 비교하여야 했다. 그래서, 품목 데이터를 누구나 쉽고 간편하게 검색 + AI를 활용하여 관련 종사자들에게 영감을 줄 수 있는 인사이트까지 제공하는 것이 목표라 하였다.

### 참고 사이트
`풀릭스(poolix)`라는 사이트에서 위에서 정리한 기획배경과 '스마트검색'에 부합하는 서비스를 제공해주고 있었다. '원재료명', '품목명', '제조사명' 총 세 개의 항목으로 식품데이터를 검색해낼 수 있었고, 검색된 결과에 대한 상세 데이터를 깔끔한 UI로 제공해주고 있었다. 나는 이러한 기능 및 UI를 참고하였고, 여기에 제품에 대한 AI가 분석한 정보들을 제공하는 방향으로 차별점을 잡아보았다.

### 핵심 기능 정의
위 내용을 바탕으로 나와 AI가 협업해서 만들 핵심 기능은 아래와 같이 정의하였다.
- 스마트 검색 : '품목명', '제조사명'으로 식약처 데이터를 빠르고 정확하게 검색.
- AI 분석 리포트 : 검색된 제품의 시장 포지셔닝과 최근 트렌드를 AI가 분석하여 3줄 요약.
- 도소매가 추이 : 최근 4년간의 예상 도매가/소매가를 추론하여 직관적인 차트로 제공.
- 대시보드: 내가 찾아본 리포트와 최근 검색어를 기록하여 나만의 소싱 대시보드로 활용.

# 트러블 슈팅
### 다중 검색 에러 (공공데이터 API의 고질적 한계)
'스마트 검색'기능에 베이스가 될 데이터를 구하기 위해 난생 처음 공공데이터 API를 활용해보았다. `풀릭스(poolix)`가 제공하느 것 처럼 삼 중 필터링 기능을 구현하려 했는데, 백엔드 없이 API로만 데이터를 처리하려다보니 난관에 부딪혔다.

식약처 공공데이터 API는 '품목명'과 '제조사명' 두 가지 조건을 동시에 검색(다중 파라미터 요청)할 경우, 내부 DB 처리 한계로 인해 `500 Internal Server Error`를 반환하는 고질적인 버그가 있었다. 프론트엔드에서 API를 직접 호출하면 복합 검색 자체가 불가능했다.

이를 해결하기 위해 Nitro를 활용해 나만의 중간 API 서버(server/api/food.get.ts)를 구축하였다. Nuxt3에서 **`server`디렉토리에 있는 파일들은 오직 "서버 단(백엔드)"에서만 실행되는데**, 서버에서 서버로(Server-to-Server) 요청을 보내면 브라우저의 제약을 받지 않으므로 CORS 에러가 아예 발생하지 않게 된다. 그리고, 식약처 서버에는 에러가 나지 않는 단일 조건(품목명)으로 1,000개의 데이터를 넉넉히 받아오게 한 뒤, **Nitro 서버 메모리 상에서 나머지 조건(제조사명)으로 2차 필터링과 정렬(최신순/가나다순)**하는 기능을 구현했다. 기능을 챙기기 위해 1000개 데이터만 가져오다보니 다중 검색시 일부 항목 검색결과가 노출되지 않는 한계점이 있긴 했지만, 공공데이터의 에러를 우회하고 다중검색이 안되는 한계점을 돌파해낼 수 있었다.

### Gemini AI로 '진짜 같은' 시장 분석 리포트 만들기
이 서비스가 다른것들과 차별되는 부분이고, 예전부터 AI 프롬프팅을 서비스에 녹여보고 싶어서 가장 공을 들였다. `@googl/genai`패키지를 통해  Gemini 2.5 Flash 모델을 연동했고, 일정한 리포트 양식을 얻기 위해 프롬프팅 양식도 작성했다. AI에게 '시장분석 전문가' 페르소나를 입혀 시장에서의 위치, 가격 변동 요인 등의 정보들을 분석하게 하였다.

처음에는 총 판매량/연간 판매량 데이터를 구하여 해당 제품의 시장에서의 영향력을 보여주고 싶었으나, 회사마다 데이터 제공 유무가 너무 다르고 AI가 쉽게 구하지 못한다는 한계점이 있었다. 그래서 하여 제품명과 제조사를 기반으로 그럴듯한 '시장 요약'과 '4년 치 도/소매가'를 얻어내도록 하여 공공데이터에 없는 정보들과 AI가 제공하는 리포트를 보며 인사이트를 얻을 수 있도록 기획안을 수정하였다.

추가로, AI가 분석한 결과를 따로 로컬스토리지에 저장하여 재분석 요청이 들어오면 저장된 값을 불러오도록 하였다. 이를 통해 토큰을 아끼고 대시보드에 쓰일 데이터를 확보해내었다.

```javascript
const prompt = `
        당신은 대한민국 식품 산업 및 B2B 유통/물가 트렌드를 분석하는 시장 분석가입니다.
        데이터:
        - 제조사명: '${factName}'
        - 품목명: '${prodName}'

        위 데이터를 바탕으로 이 제품의 최근 시장 포지셔닝과 가격 변동 요인을 요약하고, 해당 식품군의 평균적인 가격을 추론하여 최근 4년간(${currentYear - 3}년~${currentYear}년)의 합리적인 예상 도/소매 가격 추이(원화)를 추정해 주세요.

        [작성 규칙]
        1. 요약(summary)은 3문장 이내로 아주 간결하게, "~보입니다", "~평가됩니다" 등 격식 있는 톤으로 작성하세요.
        2. 가격 데이터는 해당 품목의 현실적인 시세를 반영하고, 연도별 물가 상승률 트렌드를 그럴듯하게 반영하세요.
        3. 반드시 아래의 순수 JSON 형식으로만 응답해 주세요. (마크다운 백틱(\`\`\`)이나 다른 설명 텍스트는 절대 포함하지 마세요)

        {
          "summary": "AI 시장 분석 요약 텍스트",
          "priceHistory": [
            { "year": ${currentYear - 3}, "wholesale": 3000, "retail": 4500 },
            { "year": ${currentYear - 2}, "wholesale": 3200, "retail": 4800 },
            { "year": ${currentYear - 1}, "wholesale": 3500, "retail": 5200 },
            { "year": ${currentYear}, "wholesale": 3800, "retail": 5500 }
          ]
        }
        `;
```

### 무거운 차트 라이브러리 없이 복합 차트 그리기
대시보드 팝업에 들어갈 '연간 도/소매가 추이' 차트를 그려야 했는데, `Chart.js` 같은 라이브러리를 설치하면 무거워지기 때문에, `Tailwind CSS`와 순수 HTML/SVG를 조합하여 직접 구현했습니다.

- 막대그래프: HTML `<div>`의 height 속성을 백분율(%)로 계산하여 바텀업 방식으로 렌더링
- 선그래프: 막대그래프 위에 `<svg>` 태그를 absolute로 덮어씌우고, `<polyline>`을 이용해 막대의 정중앙 좌표를 이어 트렌드 라인 구축.

"AI로 분석한 내용을 여러곳에 써야해" -> "한번 분석된 제품에 대한 정보는 저장하여 토큰 절약"
